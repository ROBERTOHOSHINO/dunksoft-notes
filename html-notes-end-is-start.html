旅するRe-Creator　沖縄篇 02　妻との共作

End is where the next Start begins.

Endは、次のStart
── 名乗る前に、名前を呼ばれるホテルで

2026年11月23日　星野晃一郎 / Roberto Hoshino

洗濯機の表示が「End」に変わった数分の遅れが、思いがけない再会を連れてきた。テラスクラブ アット ブセナで過ごした二日間を、妻の記録と私の記録で綴る。前回は沖縄篇 01「予定がないから、道は海の方へ曲がった」。

妻の記録（1）名乗る前に（Facebookより）

コロナ禍以降、とても好きで通っていた『テラスクラブアットブセナ』。隣接するブセナテラスより上の位置付けで、お子さまはお断りのウエルネスホテル。でもコロナ禍が明けて料金が高くなったので、Airbnbやキッチン付きバケーションレンタルを試していた。

久しぶり（2年半ぶりらしい）に来てみてビックリ‼️ ホテルのロータリーにレンタカーで乗り付けて、名前を聞かれないまま男性スタッフに荷物と車の鍵を預け、チェックインラウンジのソファに座り、ウェルカムドリンクが来た。すると、「ようこそ、星野さま」と女性スタッフがタブレットを手にニコニコとやって来た！😳「まだ名乗ってないけどぉ〜！」

さらに、「お誕生日でしたね」と、もう20日も過ぎてるのにシャンペンのミニボトルをいただいた。私を甘やかし過ぎじゃ無い？かつてハロウィン🎃でふざけすぎたかな？🤣

無事チェックインして、スタッフとエレベーターへ向かうとそのまた向こうのガラス扉からおかしな動きをして向かってくる男性スタッフ。扉を開けると知った顔。「来ないなぁと思ってましたよ。前回は2024年でしたね」と、横浜出身のKさん。ホテルでこんな知り合いの感じ。変な感じ。でも面白い😆

7階の7号室。部屋の割り振りもおそらく配慮してくれている気がする。ちょうどいい高さ。景色。相変わらず部屋も素敵。広さもいいしライティングも好き。大きめのクローゼット、小さいキッチンシンク、ネスプレッソ、テラスソファ、波の音。他にあるようで無い美がある。

私は忘れていた。このホテルの居心地の良さを。私にとって何もかもがちょうどいい。部瀬名岬という場所の素晴らしさ。サミットを開催するほどの立地と建物。センス、無駄のなさ、変えること変えないこと。働く人は入れ替わっていくけれど、親しみと、距離感。

思い出した。私はここがとても好きだった。とても癒される💓 帰りたくないなぁ。あ！しまった！ここには2泊しかしない。次は宜野湾に泊まる予定だった…どうする？マロ？

で、今朝、3泊延長して5泊することにした。宜野湾はキャンセル。キャンセル料かかりそうだけど払ってもいい。朝ごはんの後、延泊するとKさんに話すと「3泊増やすなんてそんな人初めてです」と爆笑していた。

「Nちゃんは和食レストランにいます、Uさんはジアッタテラスと行ったり来たりです」と知ってる仲良しのスタッフの情報も得て、滞在中に会うことになるのかならないのか、不思議な楽しみも残っている。

── 妻

私の記録（1）Endの数分

11月21日。昼はテラスのビュッフェで済ませ、食べているあいだにランドリーへ洗濯物を入れてタイマーをかけておいた。ところが戻ってみると、思っていたより時間がかかっている。表示が「End」に変わるのを待って、洗濯物を抱えてエレベーターで上がった。

扉の向こうのロビーで、Uさんに出会った。コロナ禍のころ、運動や健康に関心があるならとテラスクラブを勧めてくれた人で、妻のお気に入りのホテルマンだ。妻が書いていた「会うことになるのか、ならないのか」の答えは、洗濯機の数分の遅れが出してくれた。タイマーどおりに終わっていたら、すれ違っていたはずだ。

鷹がカラスを追う

ロビーで立ち話のつもりが、30分の情報交換になった。なかでも面白かったのが、カラス対策の話だ。

ホテルは、若手の社員を鷹匠のもとに預けて修業させ、鷹を2羽飼うことにした。網や薬で追い払うのではなく、鷹を飛ばしてカラスを寄せつけない。その対策がうまくいっているという。

自然の関係に寄り添って問題を解き、その過程で鷹狩りという日本の文化まで受け継いでいく。妻が書いた「変えること、変えないこと」が、こんなところにも生きていた。

名乗らずに通じる、ということ

妻はチェックインで、名乗る前に「ようこそ、星野さま」と迎えられた。20日過ぎた誕生日まで覚えられていた。

翌日のテニスでは、もっと驚くことが起きた。

妻の記録（2）テニスコート（Facebookより）

10時からブセナテラスでテニスをしたが、今までと大違い！とんでもない笑顔で、「レンタルシューズはいりますか？」（今まで聞かれたことない）、「ご自身のお靴はお預かりしましょうか？」ペットボトルのお水は冷たい方がいいですか？（言われたことない）、少し早めの受付だったが、予定通り11時まででいいと言われた。他にも諸々細かく優しすぎてびっくりした。いつも事務的で無愛想だったのに！

実は以前、「サーフェスの整備ができてない」と苦情を言ったことがある。沖縄だから雨風の影響も大きく受ける。でも有料で貸す以上は手入れするべきと言っちゃったのだった。それをテラスクラブのスタッフが覚えていてチェックイン翌日に｢テニスしますか？」食い気味に聞いてきて、「あぁ、しようかな」と返答したのを副支配人に伝達したらしい。結果、コートはとても綺麗になっていたが、あまりにも受付の応対が違うので気味が悪いし、私たちのために？と少々気がひけた。

レンタルラケットもコートネットも新しくなっていたので、ホテルとしてテニスコートを無くす気は無さそう。

でも別の角度から考えると、テラスホテルズは大きな企業でもある。客室スタッフは客の反応を知っていても、直接他部門に意見を言いづらい面もあるだろう。「今いるお客様の意見」と言えば、改善を依頼できる、ということか？私たちのためでなく、『このホテルの未来の客のため』だとも言える。

ブセナのすぐ近くにハレクラニ、山の上にリッツが建ち、今は恩納村にフォーシーズンズが建設中だ。沖縄中部はこれからますます高級リゾート化する。激戦だね。

── 妻

私の記録（2）記憶は部門を越える

チェックインの「ようこそ、星野さま」と、テニスコートの変わりよう。二つの出来事は、同じ仕組みの表と裏だと思う。

客の名前と誕生日を覚えているのは、ひとりのスタッフの記憶と、タブレットの記録だ。前に聞いた苦情を覚えていて、「テニスしますか？」と聞き、その返事を副支配人に伝えたのも、部門をまたいで流れた記憶だった。客室の担当者が、コートの担当部署に直接「直してほしい」とは言いにくい。けれど「いまお泊まりのお客さまの声です」と言えば、組織は動く。

私は長く、会社の中で人と仕事と時間をつなぐ仕組みを考えてきた。情報は、部門の壁の前で止まりやすい。それを越えさせるのは、立派なシステムより、覚えている人と、それを渡す一言なのかもしれない。妻の言うとおり、それは私たちのためというより、このホテルの未来の客のための改善だ。

01で、万座毛へ向かう途中に偶然通り抜けた造成地には、フォーシーズンズの看板が立っていた。ハレクラニ、リッツ、そしてフォーシーズンズ。沖縄中部の高級リゾートは、これから激戦になる。そのなかで、名乗る前に名前を呼んでくれるホテルの強さは、建物の新しさではなく、記憶の受け渡しにあるのだと思う。

色が覚えていた

Uさんと話しているとき、私は淡いミントグリーンのTシャツを着ていた。その朝、プールサイドで見かけた、キャベツの葉のような蝶と同じ色だ。そういえば、タラソプールに入るためにラウンジで買った海水パンツも、同じ系統の色を選んでいた。

名前を名乗らなくても通じる再会に、色が合言葉のように寄り添っていた。色で人を思い出し、色で確かめる。私が考え続けているテーマが、旅先でひとりでに形になったようだった。

その日の午後、中庭で結婚式があった。芝生の上の白いドレスに、居合わせた人たちから、おめでとうの拍手が鳴り響いた。知らない二人の新しいStartを、一緒に祝う。拍手でひとつの輪に加わり、また静かに自分の時間へ戻っていく。これも、妻の言う「親しみと、距離感」なのだろう。

ラウンジでハイビスカスのブレンド茶、その名も「Beauty」を飲みながら、このコラムの構想を練った。ガラスのポットに透ける淡い紅色は、01で出会ったハイビスカスしょうゆの赤とつながっている。

予定のない一日

11月22日。朝10時からテニス、そのあとタラソ。お昼は抜いて、車でPARCOシティへ向かった。途中のセブンイレブンで、ポーたまなどを買って車の中で食べ、時間を稼ぐ。久しぶりに高速道路を使ったが、景色はつまらないねと妻が言う。

大混雑の駐車場で、運良く出ていく車を見つけ、2階に停められた。目当てのZARAはすぐそこだった。私は薄手の生地をレイヤーで重ねるコーディネートが好きなのだが、ZARAには見当たらない。ノースフェイスやスポーツショップをウインドウショッピングし、GUや無印も見て回った。結局、セールで極暖が割引になっていたUNIQLOで、カシミア入りの薄手のタートルを選んだ。

帰りは58号を、夕陽を背中にのんびりとブセナまで。少し遅れたものの、大相撲は横綱対決から、二敗同士の優勝決定戦に間に合った。大の里が若元春を押し倒して、2連覇を決める一番だった。

ニュースでは、首里城正殿の復興セレモニーを伝えていた。火災から、あの日から2,580日。外では花火が上がっていた。

良い一日だった。

結び

洗濯機の「End」は、エレベーターの先の再会の始まりだった。テニスコートへの古い苦情は、未来の客のための改善の始まりになった。中庭の拍手は、知らない二人の始まりを祝っていた。そして首里城は、2,580日を経て、今日11月23日、正殿の公開初日を迎える。

Endの表示は、次のStartの合図だった。

The word End was only the signal for the next Start.

名前より先に、色が覚えていてくれた旅は、もう少し続く。首里城のことは、次のコラムで。
